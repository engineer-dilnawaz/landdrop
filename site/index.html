Questions and fixes

Is LANDrop free?

Yes. The Mac app is free, and other devices don't need anything installed.

Which computers can host it?

Macs (Apple silicon or Intel) and Windows PCs. Any device with a modern web browser can join: iPhone, iPad, Android, Windows, Linux or another Mac.

Where are my messages and files kept?

On the Mac running LANDrop, in a folder called .landrop in your home folder. Nothing is sent to a server, and the chat stays until you clear it.

Where are my messages and files kept?

On the PC running LANDrop, in a folder called .landrop in your user folder, for example C:\Users\you\.landrop. Nothing is sent to a server, and the chat stays until you clear it.

Does it need the internet?

No. Devices only need to be on the same Wi-Fi or local network as the computer running LANDrop.

macOS says it can't verify LANDrop

LANDrop isn't notarized by Apple yet. Open it once, then go to System Settings, Privacy & Security, and click Open Anyway. You only need to do this the first time.

Windows says it protected my PC

LANDrop isn't code-signed yet, so SmartScreen warns about it. Click More info, then Run anyway. You only need to do this the first time.

A phone can't reach my Windows PC

Windows Firewall is probably blocking it. Open Windows Security, Firewall & network protection, Allow an app through firewall, find LANDrop and tick Private. Also check the phone is on the same Wi-Fi, and that this network is set to Private in Settings, Network & internet, Wi-Fi.

I don't get notifications on my Mac

Open System Settings, Notifications, choose LANDrop and switch on Allow Notifications. Also check Focus isn't on. In LANDrop, Settings, Notifications lets you turn alerts off, or hide the message text so a banner only says who wrote.

I don't get notifications on Windows

Open Settings, System, Notifications and switch on LANDrop. Check Do not disturb is off. In LANDrop, Settings, Notifications lets you turn alerts off, or hide the message text so a banner only says who wrote.

A phone can't open LANDrop

Check the phone is on the same Wi-Fi as the computer running LANDrop, not mobile data. On Android Chrome, turn off Settings, Privacy and security, Always use secure connections. LANDrop runs on your local network without https, and that setting blocks it.

LANDrop stops working when my Mac sleeps

A sleeping Mac can't answer other devices. From the menu bar icon, turn on Keep Mac Awake While Plugged In. Closing a laptop's lid still puts it to sleep.

LANDrop stops working when my PC sleeps

A sleeping PC can't answer other devices. From the tray icon, turn on Keep Computer Awake While Plugged In. Closing a laptop's lid may still put it to sleep.

"Another copy of LANDrop is using port 4545"

LANDrop is already running somewhere, for example from Terminal. Quit that copy, then open LANDrop again.
